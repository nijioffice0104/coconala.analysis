# 🌈 虹オフィス ココナラ分析ツール

**ココナラの公開プロフィールから、次にやることを見つけるための分析ツールです。**

🌸　🟡　🌿　🔵　💜

</div>

## このツールでできること

- ココナラのプロフィールURLを入力して公開情報を整理
- 出品サービス、価格、販売実績、評価を一覧で確認
- 「誰向けの商品か」「商品構成」「お客さんが買うまで」を整理
- 公開情報から、まずやることを3つ提案
- ログイン後は、サービスごとの閲覧数・お気に入り・購入数を確認
- 商品ごとに「次に直す場所」を表示

## はじめて使う人へ

### 1. ツールをダウンロード

ページ上部の **Releases** を開き、最新版のZIPファイルをダウンロードします。

### 2. ZIPを展開

ダウンロードしたZIPファイルを右クリックして、**「すべて展開」** を選びます。

### 3. 起動

展開したフォルダの中にある、**`起動.cmd`** をダブルクリックします。

分析画面と、ココナラを開く専用ブラウザが起動します。

Node.jsのインストールは必要ありません。

### 4. 公開ページを分析

1. ココナラのプロフィールURLを入力
2. **「分析する」** をクリック
3. 分析結果を確認

## ログイン後の詳しい分析

1. 起動した専用ブラウザで、利用者自身のココナラにログイン
2. 分析画面に戻る
3. **「ログイン後の数字も見る」** をクリック

サービスごとの閲覧数、お気に入り、購入数を確認できます。

パスワードはこのツールに入力しません。ログイン状態は利用者のパソコン内だけで管理されます。

## うまく起動しないとき

- ZIPは、先に「すべて展開」してから起動してください
- `起動.cmd`をもう一度ダブルクリックしてください
- ChromeまたはMicrosoft Edgeがインストールされているか確認してください
- 画面を閉じた場合は、もう一度`起動.cmd`を実行してください

## 注意事項

- Windows向けのツールです
- ココナラのページ仕様が変わると、取得できない場合があります
- 分析結果には公開情報からの仮説が含まれます
- `browser-profile`は初回起動時に自動作成されます。ログイン情報が入る可能性があるため、他の人に共有しないでください

## 更新について
