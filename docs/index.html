HOW TO USE

届いたら、3ステップで使えます

Nodeなどの専門知識は必要ありません。はじめての方にも分かるように、起動用ファイルを入れています。

01

ダウンロード

上のボタンからZIPファイルを保存します。

02

ZIPを展開

右クリックして「すべて展開」を選びます。

03

起動.cmdを開く

展開したフォルダの中にある「起動.cmd」をダブルクリックします。

◎

ログイン後の分析を使うときは
起動後に表示される案内に沿って、ココナラへログインしてください。ログイン情報はこのツールに保存しません。

WHAT YOU CAN SEE

数字を見るだけで終わらせないために

◌

公開ページを確認

プロフィールやサービスの公開情報を整理して、全体像をつかめます。

↗

ログイン後の数字も確認

閲覧数・お気に入り・購入数などを、サービスごとに見比べられます。

✦

次に直す場所を考える

数字の組み合わせから、タイトル・説明・価格など、まず見る場所を整理します。
